Calculation Reference

Five calculation modules used for dataset analysis — data quality, statistics, correlation, trend, and outlier detection — plus the MVP vs. Production scope split.

All functions referenced below are implemented in analysis.py — this document is read-only reference, nothing has been edited or changed.
01

DataQualityCalculation

Goal: Determine whether the data is trustworthy before analysis.

Row Count

len(df)

Output

Total rows = 1,250,000

Column Count

len(df.columns)

Missing Values

df.isnull().sum()

Also calculate:

(
    df.isnull().sum() /
    len(df)
) * 100

Output

revenue = 2.4%
customer_id = 0%

Duplicate Rows

df.duplicated().sum()

Data Types

df.dtypes

Output

revenue float64
customer_id int64

Unique Values

df.nunique()

Useful for:

customers
products
regions

Invalid Values

Examples:

(df["revenue"] < 0).sum()
(df["quantity"] <= 0).sum()

Date Range

df["date"].min()
df["date"].max()

Output

Jan 2022 → Jun 2026

Data Quality Output

quality_report = {
    "rows": ...,
    "columns": ...,
    "nulls": ...,
    "duplicates": ...,
    "dtypes": ...,
    "unique_values": ...,
    "date_range": ...
}

StatisticalCalculation

Goal: Calculate descriptive statistics.

Sum

df[col].sum()

Mean

df[col].mean()

Median

df[col].median()

Min

df[col].min()

Max

df[col].max()

Standard Deviation

df[col].std()

Variance

df[col].var()

Quantiles

df[col].quantile(.25)
df[col].quantile(.50)
df[col].quantile(.75)

Skewness

df[col].skew()

Shows:

left skew
right skew

Kurtosis

df[col].kurtosis()

Shows:

heavy tails
extreme values

Statistical Output

statistics = {
    "revenue": {
        ...
    }
}

CorrelationCalculation

Goal: Find relationships.

Pearson Correlation

df.corr(numeric_only=True)

Output

marketing ↔ revenue = 0.91

Strong Positive Relationships

Find:

corr > 0.7

Strong Negative Relationships

Find:

corr < -0.7

Feature Ranking

Example:

Top drivers of revenue

Sort correlations.

Correlation Matrix

Output

correlation_matrix

Used by:

heatmap
dashboard

Correlation Output

    "matrix": ...,
    "strong_positive": ...,
    "strong_negative": ...
}
04

TrendCalculation

Goal: Analyze behavior over time. Requires a date column.

Daily Revenue

df.groupby("date")["revenue"].sum()

Weekly Revenue

resample("W")

Monthly Revenue

resample("M")

Growth Rate

pct_change()

Output

Jan → Feb +10%

Moving Average

rolling(3).mean()

Removes noise.

Peak Period

idxmax()

Lowest Period

idxmin()

Trend Direction

Calculate:

Increasing
Decreasing
Flat

Trend Output

trends = {
    "monthly_revenue": ...,
    "growth_rate": ...,
    "moving_average": ...,
    "peak_month": ...,
    "worst_month": ...
}
05

OutlierCalculation

Goal: Find anomalies.

IQR Method

Most common.

Q1 = revenue.quantile(.25)
Q3 = revenue.quantile(.75)
IQR = Q3 - Q1

Upper Bound

Q3 + 1.5 * IQR

Lower Bound

Q1 - 1.5 * IQR

Detect

outliers = df[
    (revenue < lower)
    |
    (revenue > upper)
]

Z-Score

Useful for large datasets.

zscore()

Outlier Percentage

len(outliers) / len(df)

Largest Outliers

nlargest(10)

Smallest Outliers

nsmallest(10)

Outlier Output

outliers = {
    "count": ...,
    "percentage": ...,
    "largest": ...,
    "smallest": ...
}
