Prompt Chains — Reasoning Layer

The LLM prompt chains that sit on top of the analysis.py calculations: turning a question into a plan, generating SQL, interpreting each calculation module, then synthesizing root cause, insight, and recommendations.

Reference only — reflects the prompt chains as specified, nothing added or altered.

core

Prompt 15

RootCauseChain

core

This is arguably the most valuable prompt.

Input

Everything discovered so far.

Prompt Role

Answer:

WHY?

Not:

WHAT happened?

But:

WHY did it happen?

Expected Output

Revenue declined because customer retention decreased and average order value fell simultaneously.
Prompt 16

InsightChain

core

Input

Everything.

Prompt Role

Transform findings into executive-level business insights.

Example

Instead of:

Average order value decreased.

Generate:

Customers are spending less per transaction, reducing overall revenue despite stable customer acquisition.

Output

Insights. Not recommendations.

Prompt 17

RecommendationChain

Input

Everything.

Prompt Role

Generate actions. Not observations. Not explanations. Actions.

Example Output

1. Launch a customer retention campaign.

2. Investigate declining order values.

3. Increase marketing investment in high-performing regions.

4. Review discount policies.
